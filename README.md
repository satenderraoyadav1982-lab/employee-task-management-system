# Employee Task Management System

A web-based Employee Task Management System developed using PHP and MySQL to manage employee tasks efficiently.

## Features
- Employee Login System
- Admin Dashboard
- Task Assignment
- Task Status Tracking
- Database Management
- Responsive Interface

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Software Requirements
- XAMPP/WAMP
- PHP 7+
- MySQL

## Installation Steps
1. Clone the repository
2. Import the SQL file into phpMyAdmin
3. Place project folder inside htdocs
4. Start Apache and MySQL
5. Run localhost/project-folder-name
